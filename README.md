## 🌟 Architecture & Key Features

FoneZone solves the two highest-cost problems in refurbished electronics e-commerce: **customer trust deficit** and **high Cash-On-Delivery (COD) Return-To-Origin (RTO) rates**.

### 1. Storefront & 360° Inspection Engine (`index.html`)
- **Studio Multi-Angle Turntable**: High-density multi-angle inspection with seamless touch/mouse scrubbing, degree indicators, and responsive camera perspective presets (Front, Back, Left, Right, Port, Top).
- **Dynamic Flaw Pinpointing**: Category-aware cosmetic flaw pins with real-time micron-level flaw telemetry (Sapphire display status, casing scuffs, battery health).
- **Amazon-Grade 32-Point Video Proof Engine**: On-demand packaging video playback proving device condition before dispatch.
- **Ambient Design System**: Ultra-clean Light & Dark mode architecture with NexG ambient micro-grids and responsive layout.

### 2. Merchant Operations Command Center (`dashboard.html`)
- **"To Whom We Send" COD Triage Queue**: Algorithmic customer trust & Khata return scoring pills evaluating delivery risk before shipping.
- **Automated 2-Way WhatsApp OTP Bot Simulator**: Upfront verification reducing courier shipping waste by up to 28%.
- **Live 4-Stage Kanban Progression**: Real-time transition from COD Verification to Packaged, Video-Recorded, and Dispatched.

### 3. Executive Client Deck (`presentation.html`)
- Interactive 8-slide pitch deck with keyboard navigation and dynamic ROI calculator showing ₹13.3L annual RTO savings.
